# Desafio de Projeto: O Dia a Dia de um QA - Prática de Testes Manuais

Este repositório contém a documentação técnica e os resultados dos testes manuais funcionais realizados na loja virtual fictícia **Swag Labs**, como parte do desafio de projeto da **DIO (Digital Innovation One)**.

## 🎯 Objetivo
O objetivo deste projeto foi simular as atividades reais de um Analista de QA em um ambiente ágil, abrangendo desde o levantamento de requisitos até a execução e reporte de bugs.

## 🛠️ Ferramentas Utilizadas
* **JIRA:** Gestão de tarefas (Task Lifecycle) e erros (Bug Lifecycle).
* **Confluence:** Documentação do plano de fluxo de trabalho.
* **Zephyr Scale:** Gestão e execução de casos de teste.
* **Miro:** Criação de Mapas Mentais.

## 📄 Documentação Disponível (Pasta /PDF)
Conforme as exigências do desafio, os seguintes documentos estão disponíveis em formato PDF:

1.  **Plano de Fluxo de Trabalho:** Definição das colunas do quadro Kanban e estados do ciclo de vida de bugs.
2.  **User Stories:** Duas histórias de usuário detalhadas com critérios de aceite.
3.  **Mapas Mentais:** Mapeamento visual de cenários para as histórias de usuário.
4.  **Casos de Teste:** * 2 Casos no formato **Step-by-step**.
    * 2 Casos no formato **BDD (Gherkin)**.
5.  **Relatório de Execução:** Evidência do ciclo de teste finalizado (100% executado).

## 🚀 Destaque do Projeto: Identificação de Defeito (Bug)
Durante a análise e execução dos testes, identifiquei uma falha crítica de UX na tela de carrinho (**Your Cart**).
* **O Problema:** A lista de itens no carrinho exibe apenas o nome e preço, omitindo a imagem em miniatura do produto.
* **Impacto:** Dificulta a conferência visual do cliente antes do checkout.
* **Ação:** Foi registrado um **Bug Report** vinculado ao caso de teste falho no Zephyr Scale, direcionado ao projeto de Bug Lifecycle para correção.
